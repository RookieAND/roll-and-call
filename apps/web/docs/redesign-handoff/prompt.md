# Claude Design 요청문 (붙여넣기용)

---

당신은 모바일 웹앱 **롤앤콜**(TRPG 세션 모집·일정 조율 서비스)의 UX/UI 리디자인을 맡은 프로덕트 디자이너입니다.

## 목표

현재 기능, 데이터, 문구를 **보존**하면서 화면별 UX/UI 수정안을 제안해 주세요. 새 기능을 만드는 작업이 아니라, 지금 있는 흐름을 더 이해하기 쉽고 일관되게 다듬는 작업입니다.

## 입력 자료

1. `brief.md`: 서비스 소개, 권한, 용어(일시 지정 동작·"마감"의 두 뜻), 전역 레이아웃·Discord 연동, 화면별 구성·상태·문구 원문·UX 문제점, 제거·병합 후보. ~~취소선~~ 항목은 이미 해결된 문제라 제안 대상이 아닙니다.
2. `screenshots/`: 412px·@2x 현재 화면 캡처. 파일·상태·테마 대응은 브리프 §5 **스크린샷 인덱스**를 보세요(파일명과 실제 내용이 다른 캡처도 거기 표시). 캡처가 없는 상태는 브리프에 "스크린샷 없음 — 설명만"으로 표시돼 있으니 설명을 기준으로 그려 주세요.

브리프와 스크린샷이 다르면 스크린샷을 기준으로 보고, 다른 점을 메모해 주세요.

**주의: 스크린샷에는 운영 환경의 실제 사용자 닉네임, 아바타, 썸네일 이미지가 들어 있습니다. 시안에 그대로 옮기지 말고 가상의 이름과 플레이스홀더 이미지로 바꿔 주세요.**

## 제약

- **디자인 시스템 '롤앤콜 UI'의 컴포넌트와 토큰만 사용합니다.** Button, IconButton, Chip, Badge, Card, Text, TextInput, Textarea, Select, Field, Avatar, AvatarGroup, Tooltip, Progress, Skeleton, Pagination, Calendar, Flex/VStack/HStack/Grid/Box/Container를 쓸 수 있습니다. 새 컴포넌트나 색이 꼭 필요하면 따로 표시하고 이유를 적어 주세요.
- **모바일 412px 프레임** 기준입니다(320px에서도 깨지지 않아야 합니다). 툴팁처럼 hover에만 의존하는 표현은 터치 대안을 함께 제시해 주세요.
- **라이트와 다크 두 테마**를 보여 주세요. 최소한 핵심 화면은 두 테마 모두 필요합니다.
- **기존 문구는 원문을 유지**합니다. 개선안은 `원문 → 제안` 형식으로 적어 주세요.
- 브리프에 없는 기능, 데이터, 권한은 추가하지 마세요. 꼭 필요하면 "기능 제안"으로 분리해 주세요.

## 산출물

1. **화면별 현재 vs 제안 시안**: 같은 상태를 나란히 비교해 주세요.
2. **변경 이유**: 브리프 UX 문제점 번호에 연결해 주세요(예: "7.3-2", "전역-8").
3. **상태별 화면**: 빈 상태, 로딩, 에러, 권한 없음, 도메인 상태(모집 중/대기 모집/모집 마감/세션 확정, 참여자/대기자/GM/비로그인, 범위 조율/일시 지정)를 포함해 주세요. 구인 상세 하단 액션 바는 분기표의 모든 행(GM-a, GM-b 포함)을 다뤄 주세요.
4. **제거·병합 후보 의견**: 브리프 §9 항목마다 동의·보류·반대와 한 줄 근거를 적어 주세요.
5. **우선순위 표**: High / Med / Low, 영향 화면, 연결된 문제점 번호.

## 작업 순서 (권장)

1. **전역 틀**: 하단 탭, 앱바, 토스트·시트·다이얼로그·툴팁, 상태 용어·배지 체계("마감" 정리), 빈 상태·로딩 패턴
2. **핵심 흐름**
   1. 구인 목록 (`/games`)
   2. 구인 상세 (`/games/[id]`): 액션 바 전체 분기, GM 메뉴(세션 채널 열기·세션 종료·삭제) 포함
   3. 참여 / 대기 신청과 취소
   4. 일정 조율 (`/games/[id]/schedule`): 주 이동, 내 가능 시간, 전체 겹침, GM 확정
   5. 참여자 관리 (`/games/[id]/participants`): 참여자 메뉴 시트, 다음 회차 시트
3. **작성 흐름**: 구인 등록 (`/games/new`, 2단계) → 구인 수정 (`/games/[id]/edit`)
4. **개인 영역**: 홈(랜딩·대시보드) → 마이페이지 (`/me`) → 내 세션 목록 → 프로필 편집 (`/me/edit`)

단계마다 요약과 다음 단계 계획을 짧게 알려 주세요.
