# 제거·병합 후보 (Deprecation Candidates)

현재 코드를 grep으로 확인해 뽑은 후보 목록이다. **실제 삭제는 하지 않았다.** 권고는 세 가지 중 하나다.

- **삭제**: 참조가 없거나 동작에 영향이 없다
- **병합(→ 대상)**: 역할이 다른 곳과 겹친다
- **유지하되 재검토**: 쓰이고 있지만 역할이 사라졌거나 흐름이 어색하다

경로는 `apps/web` 기준이다. `packages/ui/...`만 모노레포 루트 기준이다.

## 부록: 범위 밖에서 발견한 것

- `drizzle.config.ts:7`의 `schema`가 존재하지 않는 `./src/shared/api/db/schema.ts`를 가리킨다. 실제 위치는 `src/shared/server/schema.ts`라서 `pnpm db:generate`가 실패할 가능성이 높다.
- `endDate`/`confirmedAt`을 타임존 없는 로컬 문자열로 받아 서버에서 `new Date()`로 파싱한다(`src/features/write-game/api/create-game.ts:30,33`). 서버가 UTC라면 9시간 어긋날 수 있다(❓ [games-new.md](./games-new.md) §4).
